## es

Trabaja con pestañas, recupera al abrirlo las pestañas y el texto que no guardaste, y resalta la sintaxis de más de 20 lenguajes de programación. Incluye vista previa en tiempo real para Markdown, HTML, reStructuredText, SVG y CSV, varios cursores como en VS Code y un reproductor de letras LRC sincronizadas.

Tema claro, oscuro o el del sistema, y la interfaz en 33 idiomas. Sin cuentas, sin anuncios y sin recopilar datos: tus archivos y ajustes se quedan en tu equipo.

BlocPlus es software libre (GPL-3.0). El código está en GitHub.

**Novedades de esta versión**

- Interfaz en 33 idiomas: usa el idioma de Windows y se puede cambiar en Ajustes.
- Botón para abrir la página del proyecto en GitHub desde Ajustes.

- Pestañas: arrastrar para reordenar, clic central para cerrar y Ctrl+Mayús+T para reabrir la última cerrada
- Recupera las pestañas y el texto sin guardar al volver a abrirlo
- Resaltado de sintaxis para más de 20 lenguajes
- Vista previa en tiempo real de Markdown, HTML, reStructuredText, SVG y CSV
- Varios cursores y selecciones con Ctrl+clic
- Buscar y reemplazar con expresiones regulares
- Detecta y conserva la codificación (UTF-8, UTF-16, ANSI) y los saltos de línea
- Guardado seguro que nunca corrompe el archivo original
- Reproductor de letras LRC sincronizadas con el audio o el vídeo
- Tema claro, oscuro o del sistema, e interfaz en 33 idiomas

## en

**Description**

BlocPlus is a lightweight text editor for Windows that replaces Notepad. It starts instantly, takes up less than 1 MB and needs nothing else installed.

It works with tabs, brings back your tabs and unsaved text when you open it again, and highlights the syntax of more than 20 programming languages. It has a live preview for Markdown, HTML, reStructuredText, SVG and CSV, multiple cursors like VS Code, and a player for synced LRC lyrics.

Light, dark or system theme, and the interface in 33 languages. No accounts, no ads and no data collection: your files and settings stay on your PC.

BlocPlus is free software (GPL-3.0). The source code is on GitHub.

**What's new in this version**

- Interface in 33 languages: it follows the Windows language and can be changed in Settings.
- Button in Settings that opens the project page on GitHub.

**Product features**

- Tabs: drag to reorder, middle-click to close and Ctrl+Shift+T to reopen the last closed one
- Brings back your tabs and unsaved text when you open it again
- Syntax highlighting for more than 20 languages
- Live preview of Markdown, HTML, reStructuredText, SVG and CSV
- Multiple cursors and selections with Ctrl+click
- Find and replace with regular expressions
- Detects and keeps the encoding (UTF-8, UTF-16, ANSI) and line endings
- Safe saving that never corrupts the original file
- Player for LRC lyrics synced with the audio or video
- Light, dark or system theme, and the interface in 33 languages

**Keywords**: text editor, notepad, markdown, code editor, txt, programming, tabs

**Short description**: Lightweight text editor with tabs, syntax highlighting and Markdown preview.
